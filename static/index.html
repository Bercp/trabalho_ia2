MODELO DE LINGUAGEM

Conecte a sua API

A busca documental funciona sem uma chave. Para gerar respostas com IA, execute na pasta do projeto:

powershell -ExecutionPolicy Bypass -File .\configurar_api.ps1

Escolha a API, informe um modelo com suporte a ferramentas e cole a chave no terminal. Depois recarregue esta página.

A chave fica em .env, fora do Git. A API receberá a pergunta e os trechos consultados; os PDFs e os vetores ficam locais.
